# Burpee Log

Offline Android app to track **Busy Dad Program** workouts: 20-minute sessions alternating **Six-Count** and **Navy Seal burpees**, with a customizable interval timer, detailed history, a GitHub-style progress dashboard, and a level roadmap.

> **This project was built entirely with Artificial Intelligence.**
> Planning, feature definition, and prompts were created with the help of **Claude** (Anthropic), and all code was generated by **Google AI Studio**. Not a single line was written by hand. The person behind the project defined the ideas, reviewed the results, and tested the app.

## About

The [Busy Dad Program](https://www.youtube.com/@busydadtraining) is a simple training protocol: **80 minutes per week**, split into **4 sessions of 20 minutes**, alternating the Six-Count and Navy Seal burpees. Burpee Log was built for people who follow this routine and want to log each session, control the pace between reps, and track progress over time.

This is an independent project and is **not affiliated with the Busy Dad Training channel or program**.

## Features

**Interval Timer**
- Customizable 20-minute session timer with a per-minute rep cadence pattern.
  - Example `[10]`: 1 rep every 10 seconds.
  - Example `[30, 20]`: minute 1 with 1 rep every 30 s, minute 2 every 20 s, cycling until time is up.
- Automatic calculation of target reps before starting.
- Audible beep and vibration on every rep, works with the screen off.
- Background execution via Android Foreground Service with a persistent notification.
- Pausing and resuming mid-session, with time correctly accounted for.
- Ending a session early stops everything immediately and pre-fills the actual rep count in the summary.

**Warmup (optional)**
- 7-minute warmup before the main workout, using the same cadence pattern configured for the session.
- Structure: 1 min burpees → 2 min rest → 1 min burpees → 3 min rest → main 20-min workout.
- Warmup reps are not counted toward session totals.
- Can be skipped at any time with an option to go directly to the main workout.

**Session Summary & History**
- Editable rep count and optional notes at the end of each session.
- Real session duration saved (partial sessions record actual elapsed time, not 20 minutes).
- Full history with duration displayed as mm:ss, filter by exercise type, inline editing of reps, duration and notes, and session deletion.
- Manual entry of past sessions with date, type, reps, and duration.
- Line chart showing rep progression over time.

**Progress Dashboard**
- GitHub-style 12-month activity heatmap, colored by daily rep count relative to your personal record.
- Toggle between Six-Count, Navy Seal, or combined view.
- Weekly minutes card with real accumulated duration (80-minute goal).
- Consecutive weeks streak counter.
- All-time rep records for each exercise type.

**Level Roadmap**
- Official Busy Dad Program level progression (source: busydadtraining.com/levels).
- Displays current level, next target, and how many reps are still needed for each exercise.
- Progress bars for the next level; unlocked levels show the week they were achieved.
- A level is unlocked when both Six-Count and Navy Seal thresholds are reached in the same week.

**Data Management & Backup**
- Complete JSON backup and restore with full validation and preview.
- Optional automatic local backup to a user-chosen folder via Android Storage Access Framework (SAF).
- Configurable backup frequency (Weekly or Monthly) with automatic rotation (retains the 5 most recent backups).
- Optional local backup reminder notification (runs locally, max once per day, only when changes exist).
- Import past sessions from a CSV file (e.g. exported from Google Sheets) with columns `date`, `six-counts`, and `navyseals`.
- Interactive CSV preview with deduplication before saving, plus CSV export.

**Customization**
- Theme: Dark (default), Light, or follow system setting.
- Language: English (default) or Português (BR), switchable in settings independently of the device language.

**Privacy & Security**
- 100% offline: no internet permission, no analytics, no accounts, no cloud access.
- All data is stored locally using Room (SQLite) in the app's private sandbox.
- Backups are entirely optional and saved exclusively to a local folder chosen by the user.
- OWASP Mobile Top 10 security audit applied to the codebase.

## Importing Past Sessions

Prepare a CSV file with a header and one row per day:

```csv
date,six-counts,navyseals
01/09/2026,150,
03/09/2026,,60
```

- Accepted date formats: `dd/MM/yyyy` and `yyyy-MM-dd`.
- Empty or zero cells mean no workout of that type on that day.
- The app shows a preview and skips duplicates before saving.

## How to Install and Test

The project is **open source**. Anyone can install and test it.

**Option 1: Install the APK (recommended)**

1. Go to the [Releases](https://github.com/rcmnzs/burpee-log/releases) page and download the latest `.apk` file.
2. On Android, allow installation from unknown sources if prompted.
3. Open the downloaded APK and confirm the installation.
4. **To update:** download the newer APK and install it over the existing app. As long as both versions are signed with the same key (which all official releases are), Android will update the app while keeping all your data and settings.

**Option 2: Build from source**

1. Install [Android Studio](https://developer.android.com/studio).
2. Clone the repository:
```bash
   git clone https://github.com/rcmnzs/burpee-log.git
```
3. Open the project in Android Studio, wait for Gradle to sync, and run the app on a device or emulator.
