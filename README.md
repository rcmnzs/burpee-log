# Burpee Log

An **offline** Android application to log workouts from the **Busy Dad Program**: 20-minute sessions alternating **Six-Count** and **Navy Seal burpees**, featuring a customizable cadence timer, workout history, and a progress dashboard inspired by GitHub's contribution graph.

> **This project was created entirely with Artificial Intelligence.**
> Planning, feature specification, and prompts were developed with the assistance of **Claude** (Anthropic), and all source code was generated by **Google AI Studio**. No lines of code were written manually. The project maintainer guided the concepts, reviewed outputs, and tested the app.

## About the Project

The [Busy Dad Program](https://www.youtube.com/@busydadtraining) is a minimalist fitness protocol: **80 minutes per week**, divided into **four 20-minute sessions**, alternating between two exercises: the Six-Count burpee and the Navy Seal burpee. Burpee Log was created for anyone following this routine who wants to record every workout, maintain rep pacing with customizable interval timers, and track their long-term progression.

This is an independent project and is **not affiliated with or endorsed by the Busy Dad Training channel or program**.

## Features

- **Multi-Language Support (English & Português (BR))**:
  - Full support for **English** (default and fallback) and **Português (BR)**.
  - Seamless in-app language switching in Settings ("Automatic", "English", and "Português (BR)").
  - Uses modern Android 13+ per-app language APIs (`LocaleManager` & `AppCompatDelegate`) with instant UI updates, and graceful fallback for older versions.
- **Busy Dad Program Levels Roadmap**:
  - Official progression roadmap from **Level 1A to Graduation** ([busydadtraining.com/levels](https://busydadtraining.com/levels)).
  - Automatic detection of unlocked levels based on the official **same-week rule** (Monday to Sunday) requiring target reps in both Six-Count and Navy Seal sessions.
  - Overall level badge, individual discipline ranks, personal bests, and calculation of exact remaining reps and percentage to reach the next milestone.
  - Visual status for all levels: Achieved (with unlock date), Next (with progress bar), and Locked.
- **Optional 7-minute warmup protocol**:
  - Follows the official Busy Dad warmup structure: 1 min burpee → 2 min rest → 1 min burpee → 3 min rest before the main 20-minute session.
  - Distinct auditory and visual cues indicating non-scoring warmup reps and rest periods.
- **Customizable 20-minute workout timer** with flexible repetition pacing patterns:
  - Example `[10]`: 1 repetition every 10 seconds.
  - Example `[30, 20]`: 1 repetition every 30s during the first minute; every 20s during the second minute; and the cycle repeats.
  - Automatic calculation of projected total repetitions.
- **Audio beeps and haptic vibration cues** on every rep, operating reliably even with the screen locked or turned off via foreground service.
- **Session summary**: adjust actual completed repetitions and attach optional workout notes.
- **GitHub-style dashboard**: 12-month activity heatmap where cell colors represent daily repetition volume (Six-Count, Navy Seal, or combined, relative to personal records).
- **Weekly summary**: weekly active minutes calculated from real session durations (80-minute weekly goal), full-week streak counter (4800s active training), total reps, and all-time personal bests.
- **Workout history** with full visibility and editing of actual session durations (mm:ss), category filters, manual logging for past workouts, deletion, and interactive progression charts.
- **Import historical workouts** via CSV files (e.g., exported from Google Sheets) supporting `data`/`date`, `six-counts`, and `navyseals` columns.
- **Export to CSV** for easy offline backup and data ownership.
- **Multi-language support**: switch between **English** and **Português (BR)**, or follow system default automatically in settings.
- **Appearance settings**: choose between Dark, Light, or System Automatic themes with Material 3 styling.
- **100% offline and private**: no accounts, no internet connection required, and zero telemetry or data collection. Everything stays strictly on your device.

## Importing Workouts

Prepare a CSV file with a header and one row per day:

```csv
data,six-counts,navyseals
01/09/2026,150,
03/09/2026,,60
```

- Supported date formats: `dd/MM/yyyy`, `d/M/yyyy`, and `yyyy-MM-dd`.
- Empty cells or zeroes indicate that the exercise was not performed on that day.
- Before writing to the database, the app displays a preview and automatically skips duplicate records (same date and exercise type).

## How to Install and Test

This project is **open source**. Anyone can install and test it.

**Option 1: Install the APK (Recommended)**
1. Go to the [Releases](https://github.com/rcmnzs/burpee-log/releases) page and download the latest `.apk` file (e.g., `BurpeeLog-v1.0.8.apk`).
2. On Android, allow installing apps from unknown sources if prompted by your browser or file manager.
3. Open the downloaded APK and confirm the installation.
4. **How to update:** To update to a newer version, simply download the latest APK from the Releases page and install it directly over the existing app. Because official releases are signed with the same key, Android updates the application while keeping your entire workout history and preferences intact.

**Option 2: Build from Source**
1. Install [Android Studio](https://developer.android.com/studio).
2. Clone the repository:
```bash
git clone https://github.com/rcmnzs/burpee-log.git
```
3. Open the project folder in Android Studio, allow Gradle to sync dependencies, and run the app on an emulator or physical device.
